VibeCraft

From VibeCraft Wiki · A Happy Build visual learning engine where Agent completion proofs become identity, skills, drops, and collaboration signals.

Current design direction

VibeCraft uses a wiki-style information architecture: dense navigation, readable article sections, compact tables, and game-like evidence hidden inside clear encyclopedia structure.

Summary

VibeCraft turns AI-assisted creation into a personal growth wiki. A non-technical builder does not need to understand every tool log; their Agent finishes work, submits a completion proof, and the Web side updates identity, skill packs, public works, and collaboration signals.

User Non-technical vibe builders

People who build with Codex, Claude Code, Cursor, or other Agents and want progress to feel understandable.

Aha Work becomes a profile

After Agent completes a task, the user sees skills, drops, and identity update like an encyclopedia entry.

Value Knowledge enters gently

Technical progress is translated into plain-language blocks, radio notes, packs, and collaboration cues.

Agent Registration

Registration is intentionally Agent-only. The front stage asks the user to copy one instruction into their Agent. The Agent reads only authorized local context, creates a Village Pass, and returns an authorization code.

Vibe Brain

              

                Vibe Brain is the user's portable, positive memory layer. It stores distilled project traces, learned skills, collaboration preferences, and public works. The user controls the download key and can grant scoped access to Agents.
