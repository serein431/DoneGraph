# Vibe Sticker 黑客松演示包

## 赛题判断

- 赛道：AI 原生协作工具 / AI 工作小票 / Vibe Coding 辅助工具。
- 评委第一眼要看到：这不是普通任务看板，而是 AI 工作从“生成”走向“理解、确认、下次继续”的表达层。
- 核心判断：AI 会越来越会做事，但聊天记录不是工作界面；人需要一个能把 AI 工作翻译成可检查项目记忆的层。
- 本轮可记住数字：自动生成 73 张贴纸，其中 63 张已验证、10 张待验证、0 张要小心。

## 更高一层的产品判断

过去一波 AI 工具回答的是：能不能生成？

Vibe Sticker 回答的是：生成之后，人怎么理解、相信、回看、继续？

它不是再做一个 todo list，也不是把聊天记录换个皮肤。它是 AI 工作的 human-readable receipt：把 agent 做过的事、留下的证据、没解决的风险、下次该做什么，翻译成普通人愿意看的项目贴纸。

一句愿景：每一次 AI 工作结束，都应该留下一个可爱、可信、下次还能看懂的工作小票。

## 目标用户与痛点证据

- 目标用户：使用 Codex、Claude Code、Cursor 等工具连续做项目的 AI-native builder。
- 使用场景：黑客松、独立开发、小团队协作、Demo Day、长任务做到一半，明天回来还要继续。
- 真实痛点：AI 做得越多，人的确认成本越高；很难快速判断哪些真的完成、哪些有证据、哪些只是看起来完成。
- 回看痛点：下次自己、队友或 AI 继续做时，最缺的不是上下文总量，而是被整理过、带信任标记的上下文。
- 情绪痛点：长聊天让进展变得疲惫；用户需要一个轻松、可爱、但不失真的复盘入口，让知识以一种可爱的形式进入脑袋。

## 一句话产品定义

Vibe Sticker 是 AI 工作的可爱可信小票：把协作过程变成项目贴纸，让你一眼知道做了什么、能不能信、下次从哪继续。

## Aha Moment

用户打开页面时，不再看到一堆长聊天，而是看到完成、证据、风险、下一步都变成了可点击贴纸。

更重要的是，用户会意识到：这不是在管理任务，而是在把 AI 做过的工作变成自己的项目记忆。

## MVP 必做 / 可砍 / 不要做

### 必做

- Scan Session：从本地协作记录生成贴纸，让长聊天变成可浏览的工作小票。
- Sticker Wall：把目标、完成、证据、风险、阻塞、下一步变成可点击贴纸。
- Sticker Detail：解释这是什么、为什么这么判断、该不该信、下次怎么用。
- Vibe Insight：给用户正向创作洞察，但明确不是人格诊断。
- Vibe FM：生成一段可复制给下次继续用的收尾播报。
- Demo Landing：让评委打开第一页就看到产品预览、痛点、Aha 和演示路径。

### 可砍

- 账号系统、云同步、团队权限。
- 复杂项目管理字段。
- 大而全的数据看板。

### 不要做

- 不做心理诊断或负面人格标签。
- 不伪造用户反馈、市场数据或测试结果。
- 不把它讲成普通 todo list。

## 24 / 48 / 72 小时节奏

- 24 小时：跑通本地事件记录、贴纸生成、静态 dashboard。
- 48 小时：打磨可爱贴纸本视觉、Vibe Insight、演示脚本和 README。
- 72 小时：准备录屏、截图、降级演示路线和提交材料。

## Demo 脚本

### 3 分钟讲法

1. 开场：AI 工具已经很会生成了，但生成之后，人的问题变成：我怎么确认、复盘、下次继续？
2. 定位：Vibe Sticker 不是 todo list，而是 AI 工作结束时留下的一张可爱可信小票。
3. 展示 Scan Session：运行 capture/build 后，系统把这一轮工作扫描成项目贴纸。
4. 展示 Sticker Wall：完成是“菜端上桌”，证据是“作业本盖章”，风险是“雾里别跑”，下次继续是“冰箱便签”。
5. 点击一张贴纸：看它为什么这么判断、证据是什么、下次怎么用。
6. 展示 Vibe Insight：它从项目和表达里提炼正向创作洞察，不做人格诊断。
7. 收尾：复制 Vibe FM 或 stickerbook，下次打开就能直接接着干。

### 10 秒备用讲法

Vibe Sticker 是 AI 工作的 human-readable receipt：一扫生成贴纸，一点看到证据，明天回来不用重翻聊天记录。

## 页面文案

- 首页主标题：AI 工作，贴一下就懂
- 副标题：不是让 AI 多生成一点，而是让人下次回来还能看懂 AI 已经做过的事。
- 贴纸墙标题：今日贴纸墙
- 洞察标题：Vibe Insight / 灵感小镜子
- 安全边界：这些不是人格诊断，只是基于本轮项目记录的正向创作观察。

## 提交检查

- `npm test` 通过。
- `npm run typecheck` 通过。

- `npm run demo` 能生成 `.donegraph/dashboard.html`、`.donegraph/stickerbook.md`、`.donegraph/demo-kit.md`。

## 风险与降级方案

- 如果浏览器打不开：直接展示 `.donegraph/stickerbook.md` 和 `.donegraph/demo-kit.md`。
- 如果自动扫描信息不够：手动记录 goal、checkpoint、proof、done 四类事件。
- 如果评委担心洞察越界：强调 Vibe Insight 只输出正向、非诊断、可解释的创作观察。

## 当前正向洞察

这轮最适合讲的一句话：你在把抽象工作变成可感知的小物件。你对“形式”很敏感，会在工具之外追问：这个东西有没有让人愿意靠近。
