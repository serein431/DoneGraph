Completion Upload Flow
  1. Codex/Agent finishes the task and writes DoneGraph events
  2. DoneGraph generates vibecraft.json as the completion drop
  3. Agent uploads the drop to the VibeCraft Sync API or a local sync folder
  4. Web pulls the drop and refreshes drops, growth packs, and community card
  5. User only views state or edits public profile on the Web side
